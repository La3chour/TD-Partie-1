#Gestion de tâches 
Projet Python réalisé par : Achour Med Amine
#Fonctionnalités
Ajouter une tâche (le titre vide est refusé)
Afficher toutes les tâches avec leur numéro
Rechercher une tâche par mot-clé
Quitter le programme
Message d'erreur si l'option du menu est invalide

#Étapes réalisées
1 Création du menu avec une boucle while
2 Ajout de la fonctionnalité "Ajouter une tâche"
3 Ajout de la fonctionnalité "Afficher les tâches"
4 Ajout de la fonctionnalité "Rechercher une tâche"
5 Création du README
6 Envoi du projet sur GitHub

#Exécution
1 Ouvrir le dossier du projet dans VS Code
2 Ouvrir le fichier main.py
3 Cliquer sur le bouton "Run Python File" (le triangle en haut à droite)
4 Utiliser le menu dans le terminal
